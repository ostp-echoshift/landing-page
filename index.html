Pipeline Leviatan

5 niveles. Del caos al sistema en produccion.

A
Scaffold
Estructura de directorios, tokens de diseño y placeholders. El esqueleto del sistema.
B
Contenido
Design system, assets, datos seed. El sistema empieza a tomar forma.
C
Artefactos
CSS visual completo, componentes interactivos, lógica de negocio.
D
Debug
GlobalTest: responsive, links, browser check, README. Todo verificado.
E
Deploy
Push a GitHub Pages. Sistema en produccion. Cliente recibe URL.
